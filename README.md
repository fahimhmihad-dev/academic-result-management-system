# Academic Result Management System — UIA

A web-based academic result management system built for a local madrasa (Islamic school) that previously had no system at all for managing students' academic results.

🔗 **Live Website:** https://uia.getyourservicebd.store

## The Story Behind This Project

I worked at this madrasa for **one year as an English and Mathematics teacher**. During that time I saw that the school had no system for managing academic results — everything was handled manually, which was slow and error-prone.

So I built this system for them: a web application where academic results can be managed digitally instead of on paper.

This project matters to me because it was not built as a demo — it solved a real problem for a real school and its teachers and students.

## Features

- Digital management of students' academic results
- Replaces the previous fully manual, paper-based process
- Web-based — accessible from a browser without installation
- Deployed live on a custom subdomain

## Tech Stack

- HTML5, CSS3
- Built with AI-assisted development tools (Lovable / Antigravity workflow)
- Deployed live on a custom domain

## What I Learned

- Identifying a real-world problem in my own workplace and building a solution for it
- Designing a tool for non-technical users (teachers and school staff)
- Building and deploying a complete web system end-to-end
